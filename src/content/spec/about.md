# 关于本站

![青のまどろみ · Axo](/assets/images/about-axo.webp)

这是一间建在晨光与被褥之间的安静房间。**Axo** 在这里记录一点动画、游戏与前端的碎片，偶尔也写一些睡前才会想到的东西。

## 关于这个名字

「青のまどろみ」大概可以译作「蓝色的微睡」。它来自一张画面：浅蓝的头发、没叠好的被子、还没完全亮起来的早晨。本站的配色、留白与那种很轻的呼吸感，都是从这张画面里长出来的。

## 关于本站

本站是一个**纯静态**博客：构建产物直接托管在虚拟主机上，没有常驻后端、数据库或外部字体服务。

- 构建：Astro 7 + Svelte 5 + Tailwind CSS v4
- 主题：[Firefly](https://github.com/CuteLeaf/Firefly)（基于 [Fuwari](https://github.com/saicaca/fuwari) 的二次开发）
- 搜索：Pagefind（构建期生成静态索引）
- 评论：Giscus（GitHub Discussions，纯前端加载）

主题与基座的著作权归原作者所有，本站只在其上做视觉与交互调整：

- Firefly：<https://github.com/CuteLeaf/Firefly>
- Fuwari：<https://github.com/saicaca/fuwari>
